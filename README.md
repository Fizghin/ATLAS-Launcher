# ATLAS Pirate Launcher

Experimental Android HOME launcher in Kotlin and Jetpack Compose. Explore a parchment map, enter districts, and launch installed apps as text-based buildings.

## Status
Prototype. Real animated camera zoom, custom building assignments, and Android AppWidgetHost are not yet implemented.

## Build
GitHub Actions > Build Android APK > Run workflow. Download the `ATLAS-debug-apk` artifact from the successful run. You can also open this repository in Android Studio using JDK 17 and Android SDK 35.

The repository is public. Do not commit credentials or signing keys.
